# 🐾 Wild Gallery — Random Cat Explorer

A modern and responsive random cat image explorer built using HTML, CSS, and JavaScript.

The project uses **The Cat API** to fetch and display a new random cat image whenever the user clicks the Discover Cat button.

## ✨ Features

- 🐱 Fetches random cat images from The Cat API
- ⚡ Uses Fetch API with async/await
- 🛡️ Includes try/catch error handling
- 🔄 Generates a new image with every click
- 🎨 Modern and attractive user interface
- 📱 Fully responsive design
- 🧩 Dynamic DOM manipulation
- 💬 Loading, success, and error messages
- 🚫 No frameworks or external libraries

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- The Cat API

## 🔗 API Used

The project uses The Cat API to retrieve random cat images.
